# 《AI文创产品设计对传统文创设计的影响和发展研究》文字自检清单

> **用法**：改完一遍，从上到下逐项打钩；全部打钩后再送检。  
> **配套**：量化项跑 `python tools/style_metrics.py 稿子.docx`（自动出数 + 判定，不达标退出码 1）；别靠眼睛数。  
> **只改文字**：字体、字号、标题格式、段落格式、页边距、目录等排版一律不动。

---

## 甲 · 量化硬线（先跑工具，再逐项核对）

- [ ] 句均长度 ≥65 字（长句串起来写，别拆短句）
- [ ] 长句（≥60 字）占比 ≥45%
- [x] 句长变异 CV 0.45–0.65（太齐 = AI 味）
- [ ] 具体锚点 ≥0.8/千字（《规范/标准》书名号 + 带单位数字）
- [x] 行话密度 ≤18/千字
- [ ] 括号 ≤2 处、破折号 0、分号 ≤2/千字
- [ ] 顿号 10–15/千字（并列成分串起来）
- [ ] 「本文/本研究」≈2.5/千字
- [x] 摘要单独看：200–400 字、3–8 句

---

## 乙 · 结构对称（降 AI 主因 · 改法是打散，不是改词）

- [x] 无「一是…二是…三是…」编号罗列
- [x] 无「先靠…再靠…然后…」递进排比
- [ ] 无「理论上…实践上…」二元对称
- [ ] 无「X 等…认为…／Y 等则…」镜像双句
- [x] 无四字对仗三连
- [x] 高风险段单独扫过：综述 / 结论 / 研究对象 / 研究意义 / 致谢

---

## 丙 · 笼统 → 具体（锚点密度）

- [ ] 每个抽象名词（文化表达趋同 / 设计主体边界模糊 / 设计判断）出现后，补一句「具体表现在哪里」
- [x] 每个重要判断能回答三问：具体指什么 / 为什么会这样 / 对设计有什么实际影响
- [ ] 关键句落到「字段、节点、步骤、责任人」这一层
- [ ] 全文 ≥3 处具体到无法编造的信息（真实案例 / 机构名 / 数据）

---

## 丁 · 句式与连接词

- [ ] 「不能只…还要…」不连续出现（换直接陈述或拆成两句）
- [ ] 「因此 / 同时 / 此外 / 在此基础上 / 未来」同一页内不重复
- [ ] 无假靶子「真正重要的不是…而是…」（改成「本文更关注…」）
- [ ] 无机械三段式（首先…其次…最后… 连续堆砌）
- [x] 无连续设问（「谁负责、哪些内容可以使用」→ 改陈述句）

---

## 戊 · 行话层（逐条替换，禁全局替换）

- [ ] 赋能 → 具体动作（帮助设计者更快比较多个方案）
- [x] 闭环 → 完成生成、修改、打样和反馈几个环节
- [x] 抓手 / 路径 / 机制 / 范式 → 换成具体说法
- [ ] 高质量发展 / 发挥重要作用 → 降低前期试错成本 / 用于草图生成、配色比较
- [ ] 逐条改完 grep 复核（教训：曾把「逻辑分析法」错换成「道理分析法」）

---

## 己 · 语气与态度

- [ ] 结论不说满（「真正重要的变化不是…而是…」→「从设计实践看，…更值得讨论」）
- [x] 程度词有证据（明显 / 越…越… → 可能 / 容易出现 / 在部分情况下）
- [x] 无口语表演（金句收尾、机灵话）——**人味来自「具体」，不来自「口语」**
- [x] 无没有证据的因果（「必然导致」「显著提升」）

---

## 庚 · 逐章要点（对照原《文字修改意见》）

**摘要**

- [x] 补研究对象范围（如「以博物馆文创和地方非遗文创为主要对象」）
- [ ] 「AI 更适合作为…工具」后补原因
- [x] 「既…也…」工整句改日常化

**绪论**

- [x] 研究背景第二句尽快进入研究对象
- [x] 「速度提升 ≠ 质量提高」对称句改直陈
- [x] 三个问题补关系（设计流程变化 → 带来的问题 → 调整建议）
- [ ] 方法补：分析哪些文献、选什么案例、按什么标准比较；未定案例保留「测试稿」说明

**传统文创设计**

- [ ] 「通常不是…而是…」改直陈
- [x] 别把传统设计与 AI 简单对立
- [x] 评论口吻的句子改论文表述

**AI 影响**

- [ ] 「缩短时间」具体到「前期草图 / 风格比较 / 效果展示」，不说整个产品开发周期
- [ ] 学生设计者那句补「仍需结合课程知识和教师指导」
- [ ] 「转化文化元素」补限制「在输入资料较完整的情况下」
- [ ] 文化弱化那处补原因（资料缺少 / 提示语宽泛 / 训练样本常见形象占优）
- [ ] 版权不直接下法律结论，写「需结合平台规则和相关法律要求判断」

**问题分析**

- [x] 无证据程度词加限定（可能 / 容易出现 / 在部分情况下）
- [x] 抽象例子换真实案例；没有就写「若…可能…」假设式
- [ ] 「文化研究不能被替代」等论点不重复三遍（首次详说，后文一句回扣）

**发展建议**

- [ ] 每条建议补：谁来做 / 什么时候做 / 怎么检查 / 做不到怎么办
- [ ] 「记录制度」具体到：参考链接、图片来源、AI 工具、主要提示语、人工修改、采用理由
- [ ] 「文化研究—设计生成—人工审核」写成「本文建议」而非强制

**结论**

- [ ] 简要回答研究问题，不复述各章
- [ ] 大判断收窄到本文讨论范围
- [x] 补研究不足（无大样本问卷 / 无实物打样 / 案例数量有限）
- [ ] 不新增正文没分析过的内容

- [x] 数值精度前后一致
