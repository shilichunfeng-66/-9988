# 论文制作流程（独立版 · 从 orchestrator skill 提取固化）

> :lock: **使用授权声明（最高优先级）**：本流程及论文 skill 体系**仅供乐动微伴工作室成员内部使用**，不得商用、不得私自转让或分发。用户**首次使用/访问**时提示本声明一次（详见 `D:\论文工作区\使用声明.md`），并在 `D:\论文工作区\.声明已确认` 写入标记；标记已存在则不再重复提示。

> 本流程为"论文"类型项目的专属主流程。学校/申报书等内容不在此板块内。
> 执行原则：先过闸门，再动笔；每一步不可跳过。

## 第一步 · 题目与格式理解（论文板块重点）

1. **重点思考题目**（论文区别于申报书的核心环节）：
   - 多因素定范围：政策/社会需求/学科前沿/申报者资源四方面交叉，先定「题目范围」再出题；
   - 分层递进不跳步：研究领域 → 研究方向 → 现实问题 → 研究问题 → 题目；
   - 从"不对劲"进入问题：找一个可观察冲突（常识预期 vs 实际表现等）；
   - 构造研究问题链条式：具体场景 → 具体对象 → 具体现象 → 可比较差异 → 可验证疑问句；
   - 给出 5 个候选题目（六类维度改造，每个至少变两个维度）；
   - 题目诊断：拆 对象/场景/变量/理论/方法/结论强度；因果词按设计强度匹配（横断面用"关联"，实验才用"影响/效果"）；
   - 选题诊断三问：真问题（2个具体场景）/ 小切口 / 可操作。
2. **格式理解（多轮）**：询问用户做过的论文、目标期刊/学位格式；优先做能做到的格式部分，理解到位后在格式上生成内容。

## 第二步 · 博士水准主题深度分析（强制）

- 六维分析：核心价值 / 深层意义 / 研究目的 / 实现难度 / 可解决关键点 / 解决方案路径（每维 150-300 字）；
- 标题层级构思（先标题后内容）：先全部列出章节标题，逐级检查紧扣（二级答"属于一级哪个侧面"，三级答"支撑二级哪个要点"）；标题去AI化（禁"研究内容一/二"式机械命名）；10-20 字精炼命名。

## 第三步 · 文献环节（触发词命中 → 自动走「文献检索/文献检索规范.md」）

- 综述写法：先选综述类型（时序/主题/方法论/理论），每个脉络按「共识 → 分歧 → 空白」三步写；
- 文献卡片法：每篇记 研究问题/方法/主要发现/局限/与本研究关联；**他人的"局限"就是本课题的潜在创新点**；
- 需要主动检索时先写检索式：核心概念同义词（中英）→ 布尔组合 → 纳入/排除标准 → 滚雪球补漏。

## 第四步 · 正文生成

- 每个标题下段落按"总起→展开→结论"一次性写好；禁止"标题后追加"扩充（导致顺序错乱），需补充时重写整节；
- 学术写作（8E）：内容去重 / 术语一致 / 声称漂移修正（"填补空白"→"提供参考"）/ 数值有出处；
- 去AI味（8F，humanizer）：删假靶子"不是A而是B"/空话大词/万能句式/机械三段式；引号 ≤30 对/万字；保留冒号破折号与分点（学术文书需要）；
- 分工边界：8E 管严谨，8F 管自然，先 8E 后 8F，互不越界。

## 第五步 · 质量校验与输出

- research-quality-check 质检：学术规范（引用/数据）/ 内容逻辑 / 核心一致 / 时间逻辑；
- 输出格式默认 docx/md 按用户要求；引用锚点 [n] ⊆ 参考文献表；序号 1→N 正序。

## 第六步 · 评审视角预审与统计审查（2026-09-05 吸收 nature-skills 方法论 · 论文成稿后必做）

### 6.1 三份互盲评审报告（源自 nature-reviewer）

- 从 ①方法严谨性 ②结果与证据链 ③讨论与贡献定位 三个独立视角各出一份审稿意见，互不通气；
- 每条意见分级 Major（不改不能投）/ Minor（建议改），必须指向具体段落/数据，禁止笼统评价；
- 附加手稿内部一致性检查：数值跨章节一致、术语统一、图表编号与文内引用对应、图注与正文结论吻合。

### 6.2 统计审查八项（源自 nature-statistics · 实证/实验类论文必查）

①实验单位与分析单位明确(n指什么) ②重复数与独立样本 ③p值报精确值(不用"p<0.05"含糊) ④多重比较校正 ⑤效应量 ⑥置信区间 ⑦图注统计标注 ⑧统计数值跨摘要/结果/图注/讨论四处一致。缺一即补或如实说明。

### 6.3 文献精读卡升级（源自 nature-paper-card · 10项）

研究问题/核心假设/方法逻辑/数据与样本/分析策略/主要发现/**证据链**(哪个结果支撑哪个结论)/**结论边界**(适用范围与局限)/与本研究关联/可检验的研究想法。
铁律：**他人的"结论边界"就是本研究的切入空间**；引用不得越界转述（引用漂移）。

### 6.4 数据可用性声明（源自 nature-data · 投稿需要时）

按 FAIR 原则起草：仓储、获取方式、限制原因。反造假联动：未实际存放的数据不得写"已公开"，如实写 "available on reasonable request"。

## 调查分析型论文专项（2026-09-09 新增 · 毕业论文/现状调查类必读）

- 适用：题目含"现状调查与分析/现状与对策/满意度研究"等字样的实证调查类论文；
- 调研与调查方法写作（文献资料法/问卷调查法/访谈法/实地考察/数理统计等模板与句式）→ `论文制作流程/调研方法库.md`；
- 文字框架与格式母版（封面/声明/摘要/数字编号体系/22磅行距/表格与参考文献规范/附录三件套）→ `reference-db/格式参考/毕业论文格式-调查分析型-范本.md`；
- 铁律：问卷数据、百分比、访谈人数必须有真实来源，未实际调研只能写研究设计不得编造结果。
