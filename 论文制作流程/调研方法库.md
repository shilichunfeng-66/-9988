# 调研方法库 — 论文调查研究方法写作模块（2026-09-09 v2 扩充版）

> 背景：论文工作区"调研方法/调查方法"写作模块。方法谱系与样本量标准经联网核实（社会调查研究方法通用分类 + 毕业论文问卷样本量通行标准），并基于范本《芜湖市弋江区中年职场人群智慧体育信息服务现状调查与分析》实测句式。
> 配套格式规范：`reference-db/格式参考/毕业论文格式-调查分析型-范本.md`

## 〇、问卷调查法必要流程（最高优先级 · 硬规则）

**凡论文包含问卷调查部分，动笔前必须执行以下三步，不可跳过：**

1. **第一步 · 必问用户**：明确询问用户"本次问卷计划发放多少份 / 需要多少份有效问卷"，不得擅自代定；
2. **第二步 · 社会实际校验**：拿到用户意向后，结合调研对象规模、可触达渠道和通行标准做合理性推测与校验，向用户给出建议值：
   - 有效样本通行线：本科毕业论文 **200-300 份**起步（做信效度分析建议 ≥200）；预调研 30-50 份；达到通用统计底线（95% 置信、±5% 误差）需 **384 份有效**；
   - 经验法则：**有效样本 ≥ 问卷题项数 × 10**（做因子分析取 5-10 倍，最低不低于 200）；
   - 有效回收率实际通常 60%-85%，论文中常写 85%-90%；**发放量 = 有效样本 ÷ 预计有效率，另留 10%-20% 冗余**（如需 384 份有效，实际发放 420-460 份）；
   - 回收率等级参考：≥50% 足够、≥60% 良好、≥70% 非常好；
3. **第三步 · 确认后写入**：与用户确认最终数字后，按"发放 N 份 → 回收 M 份 → 有效 K 份 → 有效回收率 K/N%"口径写入论文，三个数字满足 有效 ≤ 回收 ≤ 发放，全文所有百分比与 K 保持一致。

**铁律**：数字必须有真实来源——用户实际调研过则用真实数据；未实际调研只能写问卷设计与发放计划，严禁编造回收数据与结果百分比。

## 一、调查分析型论文 = 四步调查逻辑

整篇论文围绕一条调查主线展开：**确定对象 → 选择方法 → 呈现数据 → 提炼问题与对策**。方法章（第 2 章）为第 3 章提供数据合法性，第 3 章所有结论必须能溯源到某个方法。

## 二、方法总表（按功能分类）

| 类别 | 方法 | 论文中的角色 |
|------|------|-------------|
| 资料收集类（案头） | 文献资料法/文献研究法、内容分析法、统计调查法（二手数据） | 打底：概念、现状、政策依据 |
| 实证调查类（一手数据） | **问卷调查法**、**访谈法**、实地观察法/参与观察法、实地考察法、抽样调查法、典型调查法、焦点小组（集体座谈）、专家咨询法（德尔菲）、测量/测验法 | 核心证据来源，选 1-3 种 |
| 验证干预类 | 实验法/准实验法、行动研究法 | 干预效果类选题用 |
| 分析加工类（收口必配） | 数理统计法、比较研究法、个案研究法、逻辑分析法、跨学科研究法、经验总结法 | 对数据与材料的加工论证 |

**方法数量常规**：4-6 个（文献资料法打底 + 1-2 个实证方法 + 焦点方法配角色 + 数理统计/逻辑分析法收口）。选法原则：每种方法都要在第 3 章有实际产出，写了却没用的方法删掉。

## 三、各调查法预设内容（每种方法写什么、按什么顺序写）

> 以下每法给出：预设内容要素（动笔前即可确定）+ 句式模板 + 预设参数范围（经联网核实与范本校准）。

### 3.1 文献资料法（几乎必写）

**预设内容**：①检索途径（知网/万方/Web of Science/图书馆）②检索主题（3 个左右）③整理内容（概念/现状/对象特点/政策文件）④用途定位（理论基础 + 政策依据）⑤文献量。

**句式模板**：
> 本文利用中国知网、万方数据库和{学校}图书馆等途径，检索了关于{主题A}、{主题B}和{主题C}的学术论文、专著、政策文件和研究报告，主要对{核心概念}的概念、发展现状与{研究对象}的特点和需求进行整理，作为本文的理论基础；同时查阅国家、省、市、区有关{领域}的政策文件，为调研设计和对策制定提供政策依据。本文查阅了{40-60}篇相关文献，以保证文献资料具有针对性和实用性。

**预设参数**：文献量 40-60 篇（本科）；政策文件覆盖国家→省→市→区四级。

### 3.2 问卷调查法（现状调查核心 · 流程见"〇"）

**预设内容**：①问卷维度设计（3-4 个维度，与第 3 章小节一一对应）②题型结构（单选为主、多选 2-3 题、开放题 1 题；本科 10-15 题）③发放方式（线上问卷平台 + 线下现场）④份数三步流程（必问用户→社会实际校验→确认写入）⑤样本代表性说明。

**句式模板**：
> 本文围绕{维度1}、{维度2}、{维度3}、{维度4}四个方面设计问卷，通过线上线下结合的方式开展调研，共发放问卷{N}份，剔除无效问卷后回收有效样本{K}份，有效回收率达{K/N}%。调研样本覆盖了{行业/群体列举}，年龄、性别、职业分布均衡，具备良好的代表性。

### 3.3 访谈法

**预设内容**：①访谈类型（半结构化为主；个别访谈 vs 集体座谈）②对象构成与人数③访谈内容 2-3 方面④方式与时长⑤记录整理与用途。

**句式模板**：
> 本文在问卷调查的基础上，选取{6-10}名具有不同特征的{人群}进行半结构化访谈，并访谈了{机构}工作人员{2-4}名，以补充定性研究资料。访谈对象涵盖不同年龄、职业和学历，以保证内容具有多样性和代表性。访谈内容主要包括：{方面一}、{方面二}、{方面三}。通过一对一、面对面方式开展，每次访谈持续15至20分钟，访谈结束后整理记录、提取主要观点，为现状分析和问题分析提供定性支持。

**预设参数**：受访对象 6-10 人 + 工作人员 2-4 人；单次 15-30 分钟；访谈提纲 8-10 题（放附录Ⅱ，与正文分析维度对应）。

### 3.4 实地观察法 / 参与观察法

**预设内容**：①观察对象与地点（选有特色、有代表性的点）②观察身份（公开/隐蔽、参与/非参与）③观察内容（行为、流程、使用情况）④次数与时长⑤记录方式（观察记录表、照片）⑥与问卷/访谈互证。

**句式模板**：
> 本文采用非参与式实地观察，于{时段}先后{2-3}次前往{地点}，对{观察对象}的{使用情况/运行状态/人群行为}进行现场观察记录，形成观察记录{N}份，为问卷数据提供现场佐证。

### 3.5 实地考察法（设施/平台类选题）

**预设内容**：考察对象 → 时间安排 → 考察清单（硬件、运营、服务流程）→ 记录与产出。常与观察法合并写为"实地考察与观察法"。

### 3.6 抽样调查法（需要说明代表性时单列）

**预设内容**：总体界定 → 抽样方法（方便抽样/分层抽样/随机抽样）→ 样本量依据 → 局限说明。若采用方便抽样，须在"建议"章的局限部分如实说明。

### 3.7 典型调查法

**预设内容**：选取典型（先进/中间/落后各 1-2 个）→ 选取理由（以小见大）→ 调查深度 → 与总体关系说明。"解剖麻雀"式，适合做案例对比小节。

### 3.8 焦点小组 / 集体座谈法

**预设内容**：座谈场次（1-2 场）→ 每场人数（**5-8 人**）→ 主持人与记录员 → 议题清单 → 意见归纳方式。适合补充问卷难以捕捉的群体态度。

### 3.9 专家咨询法（德尔菲，对策类选题用）

**预设内容**：专家人数（**8-15 人**，覆盖{领域}中高级职称/从业 5 年以上）→ 咨询轮次（2 轮）→ 咨询表内容 → 意见集中度处理（均值/共识度）。用于论证对策的可行性。

### 3.10 内容分析法（政策文本/平台内容/媒体报道）

**预设内容**：样本选取（时间范围+来源）→ 分析类目（编码框架）→ 统计口径 → 结论用途。句式："本文选取{时段}内{来源}的{N}篇{材料}，按{类目}进行编码统计，发现…"

### 3.11 实验法 / 准实验法（干预类选题）

**预设内容**：实验设计（前后测对照）→ 分组与每组人数（**每组 ≥30**，常规对照 40-60 例）→ 干预内容与周期 → 测量工具 → 统计方法（t 检验/ANOVA）。反造假联动：无真实实验不得编数据。

### 3.12 数理统计法（有问卷数据必配）

**预设内容**：工具（Excel/SPSS）→ 分析层次（频数与百分比 → 交叉分析 → 差异检验/相关分析，按论文深度递进）→ 与第 3 章表格的对应关系。

### 3.13 比较研究法

**预设内容**：比较对象 → 比较维度（2-3 个）→ 数据来源 → 差异归因去向（第 3 章哪一节使用）。

### 3.14 个案研究法

**预设内容**：个案选取理由 → 个案类型（个人/团体/问题）→ 深入调查方式 → 个案与总体的关系（以点带面，不作总体推断）。

### 3.15 逻辑分析法（收口必配）

**预设内容**：一句话交代"在调研数据与访谈材料基础上，运用归纳与演绎、分析与综合等方法，梳理问题成因，推导对策"。

### 3.16 跨学科研究法（可选加分项）

**预设内容**：借用哪门学科的理论/工具（如管理学 用户画像、传播学 触达理论）→ 用在第几章 → 解决什么问题。

## 四、结果分析章（第 3 章）的方法性写法

1. **章首总起**：一句话说明"运用调研数据和访谈结果，从{维度}三个方面分析现状，为问题分析和对策制定提供依据"；
2. **数据表**：三列数据表（类别/人数/百分比），表题"表3-N {表名} (n=有效样本数)"，置于表上方；
3. **解读句式**："调查结果表明，…仅有{X}%…{Y}%表示…{Z}%表示不了解。"——百分比之和=100%，口径与表一致；
4. **访谈印证**：每节配一段"访谈发现，…"的质性材料，与数据三角互证；
5. **问题章**：小标题"四字概括+具体化"（如"宣传覆盖不足，知晓率整体偏低"），节内"具体表现一/二/三"；
6. **对策章**：与问题章逐条对应，每条"一是…二是…三是…"落到可操作动作（谁做、做什么、怎么评估）。

## 五、反造假联动（铁律）

- 问卷发放/回收/有效率、所有百分比、访谈人数与引述——**必须有真实调研来源**；用户提供数据时统一口径后写入；用户未实际调研时只能写"研究设计"（方法选择与问卷框架），并在结论处注明预期实施安排；
- **问卷份数必问流程（见"〇"）不可跳过**：先问用户，再做社会实际校验，确认后才写入；
- 文献综述与参考文献走知网实测检索铁律；
- 访谈提纲与问卷题目要和正文分析的维度一一对应（正文问了什么维度，附录就要有对应题目）。
