# 调研方法库 — 论文调查研究方法写作模块（2026-09-09 新建补齐）

> 背景：论文工作区此前缺失"调研方法/调查方法"写作模块。本模块基于范本《芜湖市弋江区中年职场人群智慧体育信息服务现状调查与分析》实测提取 + 常用方法扩展，供"调查分析型论文"的研究方法章（第 2 章）与结果分析章（第 3 章）调用。
> 配套格式规范：`reference-db/格式参考/毕业论文格式-调查分析型-范本.md`

## 一、调查分析型论文 = 四步调查逻辑

整篇论文围绕一条调查主线展开：**确定对象 → 选择方法 → 呈现数据 → 提炼问题与对策**。方法章（第 2 章）为第 3 章提供数据合法性，第 3 章所有结论必须能溯源到某个方法。

## 二、常用调研方法写作模板（研究方法章 2.2.x 逐目写法）

### 2.2.1 文献资料法（几乎必写）

**要素**：检索途径 + 检索主题 + 整理内容 + 用途定位 + 文献量。

**句式模板**：
> 本文利用中国知网、万方数据库和{学校}图书馆等途径，检索了关于{主题A}、{主题B}和{主题C}的学术论文、专著、政策文件和研究报告。本文主要对{核心概念}的概念、发展现状、研究成果、{研究对象}的特点和需求进行整理，以此作为理论基础来支持本文的研究工作。同时查阅国家、省、市、区有关{领域}的政策文件，为调研设计和对策制定提供政策依据。本文查阅了{N}篇相关文献，以保证文献资料具有针对性和实用性。

### 2.2.2 问卷调查法（现状调查核心方法）

**要素**：维度设计 → 发放方式 → 发放/回收/有效数与有效率 → 样本代表性。

**句式模板**：
> 本文围绕{维度1}、{维度2}、{维度3}、{维度4}四个方面设计问卷，通过{线上+线下}结合的方式开展调研，共发放问卷{N}份，剔除无效问卷后回收有效样本{K}份，有效回收率达{K/N}%。调研样本覆盖了{行业/群体列举}，年龄、性别、职业分布均衡，具备良好的代表性。

**规则**：发放/回收/有效三个数字必须真实（来自实际调研），三者满足"有效 ≤ 回收 ≤ 发放"；有效率 = 有效/发放。**没有真实数据时只能写问卷设计与发放计划，严禁编造回收数据与百分比结果。**

### 2.2.3 访谈法

**要素**：对象构成（含人数与多样性说明）→ 访谈内容（2-3 个方面）→ 方式与时长 → 记录整理与用途。

**句式模板**：
> 本文在问卷调查的基础上，选取{n1}名具有不同特征的{人群}进行半结构化访谈，并访谈了{机构}工作人员{n2}名，以补充定性研究资料。访谈对象涵盖不同年龄、职业和学历，以保证访谈内容具有多样性和代表性。访谈内容主要包括：{方面一}、{方面二}、{方面三}等。通过一对一、面对面的方式开展，每次访谈持续15至20分钟。访谈结束后对记录资料进行整理分析，提取主要观点，为现状分析和问题分析提供定性支持。

### 2.2.4 可扩展方法（按选题需要选用，写入 2.2.4+）

| 方法 | 适用场景 | 写作要点 |
|------|---------|---------|
| 实地考察法/观察法 | 设施、场地、服务运行类选题 | 考察时间地点 → 观察内容 → 记录方式 → 与问卷/访谈数据互证 |
| 数理统计法 | 有问卷百分比数据的必配 | 用 Excel/SPSS 对回收数据进行频数、百分比、交叉分析，为现状描述提供量化依据 |
| 个案研究法 | 典型对象/典型社区 | 选取典型个案 → 深入剖析 → 说明个案与总体的关系 |
| 内容分析法 | 政策文件、平台内容、媒体报道 | 样本选取 → 分析类目 → 编码统计 → 结论用途 |
| 比较研究法 | 区域/群体差异分析 | 比较维度 → 比较对象 → 数据来源 → 差异归因 |
| 逻辑分析法 | 收尾必配 | 在数据与访谈材料基础上，运用归纳、演绎等方法梳理问题因果，推导对策 |

**方法数量常规**：3-5 个（文献资料法打底 + 1-2 个实证方法 + 数理统计/逻辑分析法收口）。

## 三、结果分析章（第 3 章）的方法性写法

1. **章首总起**：一句话说明"运用调研数据和访谈结果，从{维度}三个方面分析现状，为问题分析和对策制定提供依据"；
2. **数据表**：三列数据表（类别/人数/百分比），表题"表3-N {表名} (n=有效样本数)"，置于表上方；
3. **解读句式**："调查结果表明，…仅有{X}%…{Y}%表示…{Z}%表示不了解。"——百分比之和=100%，口径与表一致；
4. **访谈印证**：每节配一段"访谈发现，…"的质性材料，与数据三角互证；
5. **问题章**：小标题"四字概括+具体化"（如"宣传覆盖不足，知晓率整体偏低"），节内"具体表现一/二/三"；
6. **对策章**：与问题章逐条对应，每条"一是…二是…三是…"落到可操作动作（谁做、做什么、怎么评估）。

## 四、反造假联动（铁律）

- 问卷发放/回收/有效率、所有百分比、访谈人数与引述——**必须有真实调研来源**；用户提供数据时统一口径后写入，用户未开展调研时只能写"研究设计"（方法选择与问卷框架），并在结论处注明预期实施安排；
- 文献综述与参考文献走知网实测检索铁律；
- 访谈提纲与问卷题目要与正文分析的维度一一对应（正文问了什么维度，附录就要有对应题目）。
