# 科研项目思考框架

## 用途

> 社科课题优先按 `reference-db/格式参考/国社科论证与自然表达规范.md` 确定问题与材料；下文政策扫描、量化目标、技术路线及创新分类**按任务选择,不强制全部适用**；历史和理论研究不必配置问卷、因果机制或固定数量创新点。

为科研项目文档生成提供结构化思考流程,确保内容有深度、有逻辑、符合项目类型特征。

## 数据位置

项目类型思考方向文件位于: `reference-db/project-types/`

```
project-types/
├── 国家级.md      国自然/社科基金/重点研发
├── 省部级.md      省科技厅/教育厅项目
├── 校级.md        校级培育/院级课题
├── 横向.md        企业委托/技术咨询/产学研
├── 大创.md        大学创新训练计划(学生项目)
└── 教师科研.md    教师科研项目
```

## 通用思考流程(10 步)

所有项目类型共用此流程,生成时逐步展开:

### 步骤 1: 政策环境扫描
- 检索与项目主题相关的国家/省/校级政策文件
- 提取政策要点,作为立项依据的顶层支撑
- 如: "健康中国2030""乡村振兴战略""数字乡村发展战略"等
- 产出: 政策梳理与立项依据的政策支撑

### 步骤 2: 需求与意义论证
- 分析研究背景: 现实问题/学术空白/行业痛点
- 论证研究意义: 科学价值/应用价值/社会价值
- 避免空泛表述,需有具体数据或案例支撑
- 产出: 研究背景与价值论证

### 步骤 3: 研究目标凝练
- 将研究意义转化为明确、可度量的目标
- 目标不宜过多(2-4个为宜)
- 每个目标应有对应的预期成果
- 产出: 清晰的研究目标陈述

### 步骤 4: 研究内容分解
- 将目标拆分为可执行的子任务/研究方向
- 每个研究内容说明: 做什么/怎么做/预期产出
- 研究内容之间应有逻辑关系(递进/并列/支撑)
- 产出: 分点的研究内容

### 步骤 5: 技术路线设计
- 选择合适的研究方法(实验/调研/建模/开发等)
- **研究方法选择依据科研范式**(见 `reference-db/research-paradigms.md`): 先判定题目属于 5 类范式之一(调查/实验/设计/政策/理论),再挂对应必加方法论要素,避免所有项目套同一套方法
- 设计技术路径(流程图)
- 说明关键方法的具体做法
- 产出: 技术路线图与方法说明

### 步骤 6: 创新点提炼
- 按**五维度**提炼(2026-08-30 吸收 research-academic-helper): 理论创新 / 方法创新 / 应用创新 / 数据创新 / 交叉创新
- **从"局限"里挖**: 文献卡片记录的他人研究局限, 即潜在创新点清单(创新不是颠覆, 是在已有基础上补一块)
- 创新点 2-3 个为宜
- 每个创新点需有支撑逻辑(为什么是创新的)
- 避免夸大("国际领先""填补空白")
- 产出: 有据可依的创新点

### 步骤 7: 可行性与风险分析
- 研究基础: 申请人/团队的前期成果
- 条件保障: 设备/数据/平台/合作
- 风险识别: 技术/进度/资源风险
- 应对措施: 针对每个风险的预案
- **可行性四项自评**(2026-08-30 吸收 kunlun-edu-research-agent): 数据可得 / 方法掌握 / 周期够 / 创新空间——四项均充足再立题, 任一项高风险先解决再启动(应对: 提前申请权限/预留学习周期/缩小范围/换角度)
- 产出: 可行性论证与风险应对

### 步骤 8: 预期成果规划
- 成果清单: 论文/专利/实物/报告/标准
- 成果数量与级别(匹配项目层级)
- 成果交付时间节点
- **成果分三层**(2026-08-30 吸收 research-proposal-writer): 过程性成果(案例集/模板/数据) / 标志性成果(论文/报告/专利, 1-2 项即可不夸大) / 推广方式(展示/投稿/培训)
- 产出: 量化可达的预期成果

### 步骤 9: 进度安排
- 划分里程碑节点(通常按季度/半年)
- 每个节点对应具体工作与产出
- 时间安排合理(不过度乐观)
- 教育类课题进度**具体到月**(2026-08-30 吸收 research-proposal-writer): 每月有关键节点与可观察里程碑
- 产出: 进度安排表

### 步骤 10: 经费预算合理性
- 预算总额符合项目类型额度
- 科目合理(材料/测试/差旅/会议/出版等)
- 比例合理(各科目占比)
- 符合经费管理办法
- 产出: 预算明细表与说明

## 项目类型专属思考方向

读取 `reference-db/project-types/{项目类型}.md` 获取专属方向,叠加到通用流程之上:

| 项目类型 | 核心关注 | 读取文件 |
|---------|---------|---------|
| 国家级 | 科学问题凝练/国际前沿/理论创新 | project-types/国家级.md |
| 省部级 | 区域需求/政策导向/应用价值 | project-types/省部级.md |
| 校级 | 学科特色/培育方向/团队梯队 | project-types/校级.md |
| 横向 | 企业需求/量化指标/知识产权 | project-types/横向.md |
| 大创 | 学生能力匹配/创新vs可行/经费规范 | project-types/大创.md |
| 教师科研 | 方向延续性/团队配置/科教融合 | project-types/教师科研.md |

## 文档类型内容侧重

不同文档类型,思考流程的侧重点不同:

| 文档类型 | 侧重 | 核心 |
|---------|------|------|
| 申报书 | 步骤 1-6 为主 | 为什么做 + 怎么做 |
| 中期报告 | 步骤 4-9 为主 | 做得怎样 + 调整 |
| 结题报告 | 步骤 6-8 为主 | 做出了什么 + 价值 |

## 使用方式

1. 确定项目类型,读取对应的 `project-types/{类型}.md`
2. 按 10 步通用流程展开思考
3. 叠加项目类型专属思考方向
4. 根据文档类型调整侧重
5. 将思考结果转化为文档各章节内容
