# 科研智能体 · 模板与 Checklists

> 使用说明：本文件为 `edu-research-agent` 的配套模板。所有文献题录与数据均须由用户自行核验原文与来源，AI 仅辅助结构化梳理，不替代作者判断与学术诚信责任。

## 一、文献分类矩阵模板（LiteratureMatrix）

| ref_id | 题名/作者/年份/DOI | 方法范式 | 核心结论 | 局限/不足 | 研究 gap | 相关性(1-5) |
|---|---|---|---|---|---|---|
| L1 | （请填原文） | 定量/定性/综述/方法学 | … | … | … | 3 |
| L2 | … | … | … | … | … | 4 |

填写要点：
- **方法范式**：区分实验、准实验、相关、横断、现象学、扎根、案例、系统综述等。
- **核心结论**：一句话提炼，避免照搬摘要。
- **局限/不足**：作者自陈局限 + 你发现的空白。
- **研究 gap**：明确指出"尚无人研究/方法单一/对象受限"等。
- 相关性 5=直接奠基，1=仅背景相关。

## 二、论文结构（IMRaD）框架

- **引言 Introduction**
  - 研究背景与概念界定；文献缺口（gap）；研究问题 RQ；研究意义（理论/实践）。
- **方法 Methods**（须可复现）
  - 研究设计、对象与抽样、变量/工具（量表来源与信效度）、流程、数据分析方法、伦理审查。
- **结果 Results**（客观、不与讨论混写）
  - 按 RQ 分小节呈现；图表自明；统计量与效应量齐备。
- **讨论 Discussion**
  - 解释发现、与既有文献对话、理论/实践意义、局限性、未来研究。
- **结论 Conclusion**：回应 RQ，浓缩贡献。
- **图表规范**：图题在图下、表题在表上；图表自包含可读；编号连续；结果文字不重复图表全部数据。

## 三、研究设计 Checklist

### 定量设计
- [ ] 研究类型（实验/准实验/相关/横断）明确
- [ ] 变量定义与操作化（自变量/因变量/控制变量）
- [ ] 抽样方法与样本量估算依据
- [ ] 测量工具来源、信度（ reliability ）与效度（ validity ）说明/预检验
- [ ] 统计分析方法预先注册或预先说明
- [ ] 伦理审查（IRB）与知情同意

### 定性设计
- [ ] 研究范式（现象学/扎根/案例/民族志）明确
- [ ] 目的抽样/滚雪球等抽样策略
- [ ] 数据收集工具（访谈/观察提纲）经 pilot 检验
- [ ] 编码方案与信度（同行校验/三角验证）
- [ ] 数据饱和判断标准
- [ ] 伦理：匿名化、知情同意、数据留存与销毁

### 混合方法
- [ ] 设计类型（并行/sequential）、优先级、整合点（mix point）
- [ ] 两种范式权重与衔接逻辑清晰
