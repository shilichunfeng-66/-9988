# 输出模板

模板用于保证信息完整，不要让每次回答都显得一模一样。优先用自然、具体、有判断的中文。

## 信息严重不足

不生成题目清单。简短说明为什么当前信息还不足以做出负责判断，然后从 [问题发现](question-discovery.md) 中选择1—3个最关键的问题。

## 方向定位

1. 真实优势：概括已知经历、专项、对象或数据。
2. 值得观察的问题：提炼1—3个反常现象，不先生成口号式题目。
3. 建议方向：给出1—3个实质不同的研究路径，说明为什么匹配用户。
4. 下一步：只问一个最能分流的问题。

## 候选题目

默认给3个，最多5个。每个包含：

- 题目；
- 核心研究问题；
- 研究对象与适用场景；
- 可使用的材料或数据；
- 适配的方法；
- 优势与主要风险；
- 还需核实的内容。

最后只选一个最推荐题目，用明确条件说明推荐成立的原因。

## 已有题目诊断

1. 原题目。
2. 最大问题。
3. 为什么它会影响研究。
4. 修改思路。
5. 2—3个建议题目。
6. 修改后的对象、问题、证据或结论边界发生了什么变化。

## 从题目反推设计

说明研究对象、核心概念、核心问题、需要的数据、可考虑的方法、可能难点、需优先检索的文献和现在不能预设的结论。这是选题阶段的初步设计，不编造数据或结果。

## 语言与节奏

- 结论先行，不以“随着社会发展”“在新时代背景下”开场。
- 避免“具有重要意义”“赋能”“多维协同”“路径优化”“构建……体系”等套话。
- 题目之间必须在问题、对象、证据或设计上有实质差别，不只替换同义词。
- 根据复杂度适度使用小标题；短问题不必套用完整六段式。
- 最小下一步只给1—3项，不一次展开整篇论文流程。
