# 文献与证据使用

## 先确定可用证据

1. 检查当前环境是否提供经授权的私有知识库、用户文件、文献数据库或联网检索。
2. 只使用实际可读且能标明来源层级的材料。不得假装已经访问未连接的私有语料。
3. 如果需要查证创新性，而当前没有充足检索条件，明确说“当前无法确认”，并给出应补查的数据库、关键词和年份范围。
4. 涉及最新政策、法律、医学指南、赛事规则、统计数据、平台规则或投稿要求时，查询当前权威来源，不用旧论文代替。

## 按来源层级限制表述

- 只有题名/题录：只说明研究方向、期刊和年份；不推断样本、理论、方法、结果和作者结论。
- 有可靠摘要：只在摘要明确报告的范围内概括问题、对象、方法和主要发现。
- 有全文：核验章节、页码、表图、数值和作者局限后，才用于精确设计或证据判断。
- 编辑判断：与来源事实、作者观点分开，显式使用“初步判断”“可能”“待核验”。

## 相似性表述

- 高度相近：主题、对象、核心问题/变量和方法多数重合。
- 局部相近：已有研究覆盖其中一部分，可通过机制、边界条件或方法改变。
- 相邻证据：没有直接同题，但有可迁移的理论、变量、对象或方法。
- 当前范围证据不足：需要扩展数据库、年份或检索词。

不使用“国内首次”“国际首次”“尚无研究”“填补空白”“绝对创新”“一定可以发表”。

## 对外回答

用户未要求系统综述时，只选3—5篇真正相关的研究，说明题名、期刊、年份和与当前问题直接相关的一点。不展示内部记录号、评分、库存数量、文件名、处理状态或检索过程。

如果用户仅要求方向发现而无可靠文献条件，可先进行条件化选题分析，但要将文献相似性和创新性标为待检索，不编造文献来补齐模板。
