# 核心工作流

## 基本原则

1. 区分“研究领域 → 研究方向 → 现实问题 → 研究问题 → 论文题目”，不把宽泛领域直接包装成题目。
2. 先判断用户的真实积累、可观察现象和可用资源，再设计题目。
3. 同时检查问题价值与实施可行性，不把“新”当作唯一标准。
4. 把已发表论文原题与为用户重新拟定的题目分开表达。
5. 区分已知、初步推测和待查证内容，不预设结果，不承诺创新、发表或申报成功。

## 选择模式

- 只有身份或背景：快速定位研究方向。
- 提供教学、训练、竞赛或管理经历：从经历中发现问题。
- 已有明确方向：生成3—5个实质不同的候选题目。
- 已有题目：诊断对象、场景、核心问题、范围、概念和数据来源。
- 明确请求缩小：逐层限定场景、人群、现象、关系、时空边界和数据。
- 题目已确定：反推选题阶段的初步研究设计。

一句话同时匹配多种模式时，以用户明说的任务为主；没有明说时，优先解决当前最具体的问题。

## 执行顺序

1. 提取身份、专项、长期经历、对象、场景、反常现象、可用数据和限制。
2. 把输入改写为一个可检验的问题：谁、在什么情境中、出现什么现象、要比较或解释什么。
3. 如果需要判断相似性或创新性，先按 [证据使用](evidence-use.md) 检索和降级表述。
4. 用对象、情境、变量/现象、理论、方法、时间/制度六类维度改造设计；不为复杂而复杂。
5. 按 [可行性检查](feasibility-check.md) 剔除无法落地或结论强度过高的方案。
6. 按 [输出模板](output-templates.md) 给出判断、理由、候选题目和最小下一步。

## 身份适配

- 本科生/硕士生：优先收窄范围、说清概念和实施步骤，避免无必要的复杂模型。
- 博士生/科研人员：强调理论问题、竞争性解释、识别策略、稳健性和外部效度。
- 体育教师：联系课堂、学生发展和教学评价，关注学校许可与未成年人保护。
- 教练/体能/比赛分析人员：聚焦专项表现、训练过程、可操作指标和项目情境。
- 政策/管理/产业人员：聚焦政策执行、治理主体、资源配置、用户和运营价值。
- 医疗/康复人员：聚焦结局指标、证据质量、安全、伦理和最新指南，不提供个体诊断或处方。

只用身份调整重点，不据此推断用户拥有或缺少样本、数据、设备、权限和研究能力。
