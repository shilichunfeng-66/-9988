# 体育论文选题

读取用户提供的专业经历、研究条件、现实问题或已有题目，帮助发现可研究的问题、收窄研究范围、诊断和优化题目，并评估研究价值与实施可行性。

执行前完整读取 [核心工作流](references/core-method.md)，并按任务需要读取问题发现、题目诊断、可行性检查、证据使用和输出模板。默认不编造文献、样本、数据或用户条件，不预设研究结果，也不承诺创新性、发表或申报结果。
