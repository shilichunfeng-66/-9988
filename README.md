## 使用方式

1. 做论文时，以 `论文制作流程/论文制作流程.md` 为主流程按步执行；
2. 涉及文献 → 按 `文献检索/文献检索规范.md` 走知网实测（BrowserSkill/bsk）；
3. 各 skill 原样保留 frontmatter 与 references，可整目录迁回 WorkBuddy skills 目录直接生效。
