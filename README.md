## 🎓 大学生毕业论文方向（2026-09-17 新增 · 本科专属）

> 本科毕业论文的**全链条方向**：体例与目录/三线表 + 双层降 AI + 工具链 + 执行 SOP。
> 实测战绩：《体医融合视域下大学生体质健康促进的困境与路径研究》测试稿 PaperPure **53.1% → 20 多**。

### 配套文件

| 文件 | 内容 |
|------|------|
| `reference-db/格式参考/本科毕业论文体例规范.md` | 文档顺序（目录→摘要→Abstract→1-4章→参考文献→致谢→附录）/ 阿拉伯多级编号 / 第3章「现状—问题—对策」一一对应 / 版面字体 / 目录 TOC 域 / **三线表三条线参数** |
| `reference-db/格式参考/本科生毕业论文文风基准-实测.md` | 降 AI 第一层**语体**六条（+正文口径测量规则）＋ 第二层**结构对称八式** |
| `tools/build_thesis.py` | 由新式 md 生成体例合规 docx（三节/目录域/三线表/页眉页脚页码） |
| `tools/style_metrics.py` | 正文口径文风指标 + 结构对称扫描 + 硬线判定（送检前预筛） |
| `tools/check_doc.py` | 字数 / 文献编号正序 / 编号=正文顺序 / 锚点⊆文献表 / 匿名 / 禁词 |

### 工具用法

```bash
python tools/build_thesis.py 源文件.md 输出.docx          # 生成体例合规 docx
python tools/check_doc.py 输出.docx                      # 硬规则检查
python tools/style_metrics.py 输出.docx                  # 文风指标 + 结构对称扫描
```

更新目录页码：用本机 Word 后台打开 → `TablesOfContents.Update()` + `Fields.Update()` → 保存（可顺带导出 PDF 自查）。

### 核心结论（降 AI）

**语体决定下限，结构决定上限。** 句法拉平后仍被标红的段落，几乎全部命中「结构过于对称」——`一是…二是…`、`先靠…再靠…`、`理论上…实践上…`、`X等…Y等则…`、定义式长列举、四字对仗三连、模板致谢。改法是**打散对称**，不是改词。
