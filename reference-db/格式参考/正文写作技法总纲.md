# 正文写作技法总纲（题目—内容逻辑 · 描述方式 · 思考层数）

> **定位**：把大创线、教师科研线、论文线三条线走下来沉淀的**正文写作技法**抽成一份通用总纲。
> **适用范围**：三条线通用；文末附「三线差异对照」。
> **来源**：教师科研线 二-A/二-C/二-D/二-E/二/三-A~三-K、大创线「六·正文描述逻辑」、论文线「中文论文生成子流程」，经体医融合申报书等项目实战校验。
> **使用方式**：写作前过「第三部分·思考层数」的门禁；写作中套「第一部分·题目内容逻辑」与「第二部分·描述方式」；完稿后跑各线交付检查。

# 第一部分 · 题目与内容的逻辑关系（三层锁定）

> **铁律**：整个内容必须与题目高度符合，严格围绕标题展开；严禁套用其他项目/文件的内容填充（二-A）。

## 1.1 第一层：题目的构成要能撑起内容

| 要素 | 要求 | 反例 |
|------|------|------|
| **方法词** | 驱动/辅助/基于/面向/视域下…（四选一，不叠加） | "基于…与…驱动下的…"（叠加） |
| **研究对象** | 具体、可界定（人群/系统/现象） | "大学生"（过泛，须限定为"体质弱势群体"等） |
| **研究动作** | 一个核心动作（构建/影响机制/评估/优化） | 并列两个动作（"构建与应用"可，但不能三四个） |
| **落点后缀** | 与研究类型匹配（关键技术研究/影响机制研究/模式构建） | 万能"研究" |

**关键词 = 四层五词**：方法层 1 + 对象层 1-2 + 技术层 1 + 机制层 1；禁止同层堆叠（全写深度学习/机器学习/神经网络即失分）。
**一题三稿法**：方向稿（对象+问题）→ 定式稿（套四要素）→ 精修稿（删冗词、统一动词、核字数与学科落点）。
**载体适配**：社科活页长题 20-30 字；理工/交叉 12-25 字；论文 20-25 字（与研究问题、结论呼应）。

## 1.2 第二层：题目承诺 ↔ 内容兑现（一致性三查）

**题目里的每一个承诺词，都必须在正文中有兑现；正文里出现的核心内容，都必须在题目中有回扣。**

| 查什么 | 怎么查 | 判为错配的信号 |
|--------|--------|---------------|
| **① 承诺词兑现** | 把题目拆成承诺词（机制/路径/体系/模式/关键技术/规律…），逐个到目标与内容里找落点 | 题目写"机制"却只做效果验证 → 机制缺失，要么改题要么补内容 |
| **② 层级匹配** | 题目的尺度 ↔ 内容的尺度 | 题大内容小（"体系构建"却只做单点）；青年项目写体系、重点项目只做单点 |
| **③ 关键词回扣** | 每部分（章节/大段）末句回扣题目关键词一次 | 通篇找不到题目前的落点 → 跑题 |

**论文的特殊形态**：题目 = 研究问题 + 对象 + 方法/发现指向；承诺—兑现链落在 **Abstract/引言（提出问题与承诺）→ 方法（如何回答）→ 结果（证据）→ 讨论（兑现承诺 + 划边界）**；结论不得超出证据。

## 1.3 第三层：内容自身的结构对映

| 技法 | 做法 | 适用 |
|------|------|------|
| **模块法** | 总起一句"围绕{核心主线}设置 N 项内容" → 每模块"命名（按实际内容，禁'内容一'）+ 做什么 + 产出什么" → 模块间写清递进 | 研究内容 |
| **链条对映** | 研究方案/步骤与研究内容模块**一一对应**，每步 = 方法 + 对象 + 产出；禁出现内容里没有的步骤 | 研究方案、技术路线 |
| **四列对应** | 目标（可考核）↔ 内容模块 ↔ 可验证指标 ↔ 采用方法；**无孤儿行**（每个目标有内容承接、每项内容有指标兜底、每个指标有方法产出） | 教师科研、基金类 |
| **三列简化版** | 目标 ↔ 内容模块 ↔ 可交付产出（指标可为"完成 N 份问卷 / 形成 Y 份方案"） | 大创、学生项目 |
| **边界式描述** | 每条内容写"重点研究什么 + 暂不涉及什么"，用"不再全面涉及/暂不深入探讨"划定可行范围 | 全部（让评审看到可控性） |

# 第二部分 · 描述方式（段落级技法）

## 2.1 论证段落四步法（所有段落的基本式）

```
① 论点句    本段说什么，一句话立住
② 论据展开  为什么这么说（现状依据、原理论证、需求分析）
③ 例证/事实 用什么证明（调研情况、数据、案例、文献）
④ 回扣题目  一句话收口，点明本段支撑题目的哪个环节
```
**要点**：②③ 不可省；只写①④就是空话；一段只说一件事；不写"本课题很重要"这类无依据论断。

## 2.2 述—评—转（文献述评与现状部分的收束式）

每条文献线/现状小节按三步收束：**述**（别人做到什么程度）→ **评**（哪里不够）→ **转**（所以本研究做什么）。
取代"综上所述"式万能过渡；三条线索收口到三点局限，再由局限反证本课题价值。

## 2.3 数据与证据句式

| 场景 | 句式 | 注意 |
|------|------|------|
| 表前引导 | "为考察…，结果见表 X" | 表必须有正文引用 |
| 表后解读 | "占比最高 {X}%，其次为 {Y}%；反映出…" | 数字与表内一致，不重复罗列全表 |
| 质性印证 | "访谈发现…" | 与量化结果相互印证 |
| 文献引用 | 观点后紧跟 [n] | 引而未用 = 装饰 |
| 结论边界 | "在 A 条件下成立，B 时需谨慎推广" | 无边界 = 过度声称 |

## 2.4 理论引用与机制解释

- 引用必须**给用途**："借鉴{理论}的{概念}解释{A}的成因"，禁"借鉴了 XX 理论"空转；
- 机制用**因果链**写足：因为…→ 所以…→ 因此…（三层）；
- 论文中机制落在引言（机制假设）与讨论（机制解释）两处，须前后一致。

## 2.5 开篇与收尾定式

- **开篇三选一**（禁"随着…的不断发展"起头）：①现实问题起 ②需求/现状起 ③概念界定起；**开篇首句须含题目关键词**；
- **收尾两句式**：回扣式（"因此，本研究的{核心方案}…"）/ 衔接式（"上述问题指向{下一步}，故本研究先…"）；
- **每一部分末句回扣题目一次**。

## 2.6 图表说明

图前引导句 → 图 → 图注（在下、居中、按物理顺序编号）→ 图后解读句；表注在上。
**铁律**：图表必须在正文被引用；图内文字与正文一致；**不画无数据支撑的数据图**（未实测不得编造）。

## 2.7 篇幅节奏

- **论证主体占 60-75%**（研究内容 + 思路方法最重），创新与成果各约 10%，忌平均用力；
- 有同底板范本时**以范本实测字数为锚**（如范本某节 4784 字 → 目标区间据此定）；
- 各节篇幅按评分职能定，不按"看起来均衡"定。

## 2.8 申报书/论文通用 AI 腔黑名单

随着…发展 ｜ 赋能 / 抓手 / 闭环（除非确有机制含义）｜ 不是 A 而是 B ｜ 综上所述 ｜ 提供有力支撑 ｜ 浅析 / 初探 ｜ 机械"创新点一/二""研究内容一/二"式命名。
→ 逐条给了改法后仍以**学术化客观表述**为准；术语全文统一。

# 第三部分 · 思考层数（写作前必过的门禁）

> **四层门禁，逐层过、不可跳**。每层都有"产出物"，产出缺失 → 不得进入下一层。

| 层 | 名称 | 触发时机 | 追问什么 | 产出物 |
|----|------|---------|---------|--------|
| **L0** | **题目两轮七问** | 出题时 | 七问（价值/实际/可实现/文献/科研水平/方法要素/**能否凝练科学或技术问题**），两轮走（第二轮反证 + 延续性 + 区别性） | 候选题目 + 淘汰理由 |
| **L1** | **双轮确认门禁** | 定题后、动笔前（有底板文件时） | 轮次一：文件要求「大方向 + 小方向」拆解 → 重点/一般/有就行 三分档 → 交用户确认；轮次二：题目 / 重点解决内容 / 解决方案 / 最终成果 四问对齐 | 重点分级确认表 + 构建思路确认单 |
| **L2** | **三轮研究探讨** | 题目、大纲确定后，写作前 | ①题目解构（核心概念/对象场景/核心问题/贡献指向）②大纲论证（每节论证什么/证据链/闭环/图表规划）③研究深化（贡献定位/创新差异/潜在质疑/结论边界） | 关键词矩阵 + 一句核心研究问题 + 结构论证 + 贡献定位 + 质疑应对 + 结论边界 |
| **L3** | **四轮梳理逻辑** | 生成与返修时都用 | ①时间型（全周期时序）②机构型（主体间资源嵌入）③评审专家型（逻辑完整/制度合理/资源可行/风险可控）④专家审核轮（整体校验，有问题回对应轮修，不全文重写） | 四轮自检记录 |
| **L4** | **科研质量三性** | 动笔前校验，正文中体现 | **理论性**（回应/修正了哪个理论问题？机制怎么解释？）**科学性**（证据链完整吗？什么条件下成立/不成立？）**可实现性**（每项内容都对应可得的数据与人力吗？周期与成果匹配吗？） | 三性结论（任一不达标 → 回题目与框架层修） |

**层与层的分工**：L0 决定"做什么题"，L1 决定"按什么重点写"，L2 决定"写得深不深"，L3 决定"层次清不清"，L4 决定"站不站得住"。
**共同硬规则**：每问都要给结论与依据（真实文献/数据），不空喊；结论以简表留存，供写作时对照防漂移；涉事实/文献/数据一律遵守反造假与文献实测铁律。

# 第四部分 · 三线差异对照（用哪套、不用哪套）

| 维度 | 大创 | 教师科研 | 论文 |
|------|------|---------|------|
| 目标 | 方案与产品落地、学生可执行 | 学术价值 + 机制创新，评审通过 | 学术贡献 + 同行评审通过 |
| 题目尺度 | 对象 + 场景 + 要做的东西 | 四要素定式 + 学科归属 | 研究问题 + 对象 + 方法/发现指向，避免"XX 研究" |
| 逻辑骨架 | 模块法 + 链条对映 + 目标—内容—产出三列 | 四列对应（目标-内容-指标-方法）+ 科学问题凝练 + 机制解释 | IMRaD 承诺—兑现链 + 证据门控 |
| 篇幅配比 | 项目方案 60-70% | 论证主体 60-75%，研究内容/思路方法最重 | 方法与结果为主，讨论兑现承诺 |
| 思考层数 | L0 + L2 + L4 简化版 | L0-L4 全量 | L0 + L2 + L4（论文版）+ 统计审查 |
| 参考文献 | **不设要求** | 必须实测、编号=正文首次引用顺序、中英混排 | 必须实测；精读卡 + 结论边界不得越界转述 |
| 特有环节 | 可行性三段论（条件/路径/风险） | 专业范围审查 + 匿名处理 + 反查对照法 | 三份互盲评审 + 统计审查八项 + 数据可用性声明 |
| 深度版 | — | research-plus | 论文 Plus 版（见 `research-writing` 第十节） |
