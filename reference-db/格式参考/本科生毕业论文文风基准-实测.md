# 本科生毕业论文文风基准（实测 · 源自用户本人终稿）

> 来源：《芜湖市弋江区中年职场人群智慧体育信息服务现状调查与分析》（社会体育指导与管理专业，2026 届，11306 中文字）。
> 用途：本科毕业论文（论文线「场景 6」）写作与降 AI 改写的**语体基准**——不是猜的，是从真人定稿里量出来的。

## 一、量化指标（人写定稿 vs AI 高风险稿对比）

| 指标 | 人写定稿 | 被标红稿（PaperPure 53.1%） | 规则 |
|------|---------|---------------------------|------|
| 句均字长 | 72 字 | 45 字 | **写长句**，一句 60-120 字为常态 |
| 句长变异 CV | 0.83 | 0.56 | 长短交错幅度要大 |
| 长句（≥60 字）占比 | 53% | 19% | **过半句子要是长句** |
| 括号 | 10 处/1.1万字 | 每段都有 | **几乎不用括号**，解释写进句中 |
| 分号 | 1.1/千字 | 3.3/千字 | 少用分号，用逗号把分句串起来 |
| 破折号 | 0.4/千字 | 多处 | 基本不用 |
| 顿号 | 15.7/千字 | 7/千字 | **多用顿号并列**（认知、使用、需求） |
| 「本文」 | 29 次 | 10 次 | **高频用「本文」起句**，不刻意换词 |

## 二、句法特征（照着写）
1. **长句串联**：把多个小句用逗号连成一句，说完再打句号，例如"本文利用中国知网、万方数据库和池州学院图书馆等途径，检索了关于智慧体育、中年职场人群健身和公共体育信息的学术论文、专著、政策文件和研究报告"；
2. **段首常常就是"本文/本研究 + 动作"**：本文利用……、本文在问卷调查的基础上……、本文运用调研数据和访谈结果……
3. **关键术语反复使用，不做同义词替换**（"智慧体育信息服务"一段内出现多次）；
4. **顿号列举成串**：现状分析、问题分析和对策制定；认知程度、使用情况、实际需求；
5. **平实收尾**，不做"回扣题目"式的漂亮收口，常常以"为后续研究提供参考/支持"这类朴素句结束；
6. 允许口语化的连接（不过、比如、目前、就研究范围而言），不需要每句都书面化。

## 三、内容特征（降低 AI 判定的关键）
1. **具体到无法编造**：地名（弋江区）、机构（讯飞智元）、平台名（市级智慧体育服务管理平台）、年龄区间（35-55 岁）、访谈人数（6 名 + 工作人员 2 名/4 名）、访谈时长（15-20 分钟）、文献数（40 多篇）；
2. **数据来自真实调研**，不用"研究表明"这类模糊归因；
3. 章节标题朴实（研究设计、调研实施、结果分析），不追求对仗与文学性。

## 四、改稿自检（写完逐条过）

> 别靠眼睛数——跑 `python tools/style_metrics.py 稿子.docx`（给两个路径就是前后对比），按正文口径出数并自动判定；不达标退出码 1。

- [ ] 句均长度 ≥60 字？长句占比 ≥40%？
- [ ] 括号是否已经写进句中（≤2 处）？
- [ ] 分号是否控制在 2/千字以内？破折号是否为 0？
- [ ] 关键术语是否重复使用而没有被"换词"？
- [ ] 是否有 3 处以上具体到无法编造的信息？
- [ ] 段首是否有一部分直接用「本文/本研究」起句？

## 五、测量口径与类型差异（2026-09-17 补充）

- **测量口径**：指标按**正文口径**统计——从第一章标题起、到「参考文献」止，剔除封面、目录、摘要、Abstract、关键词、附录。摘要是整段长句，混入会把句均与 CV 一起拉高，造成"假达标"；摘要单独看，控制在 200-400 字、3-8 句。
- **类型差异**：上表数值来自**调查实证类**论文（问卷 + 访谈，天然有大量并列项与数据句）。**理论推演类**（文献 + 逻辑分析，如体医融合测试稿）的**顿号密度**与**句长变异 CV** 天然更低——顿号 10-12/千字、CV 0.5-0.6 即属正常，**不要为凑数值硬塞并列项**，那会读起来像 AI 堆排比。
- **可迁移的硬指标**（各类型都照做）：句均 ≥65 字、长句（≥60 字）占比 ≥45%、括号 ≤2 处、破折号 0、分号 ≤2/千字、「本文/本研究」≈2.5/千字。
- **理论推演类的最大短板是"具体信息密度"**：没有真实数据可依靠时，用**真实存在的规范与机构名**（如《国家学生体质健康标准》、校医院、体育部、学生体质健康测试中心）替代编造数字；一旦补入实测数据，该项可显著改善。

## 六、第二层：结构对称（2026-09-17 实测新增 · 比语体更关键）

句法层面拉平之后仍被标红的段落，几乎全部命中「**结构过于对称**」。也就是说，**语体决定下限，结构决定上限**。

| 高风险句式 | 典型写法 |
|-----------|---------|
| 编号罗列 | 一是…，二是…，三是… |
| 递进排比 | 先靠…再靠…然后…并用… |
| 二元对称 | 理论上…，实践上… |
| 镜像双句 | X等…，认为…，并从A、B、C层面…／Y等**则**… |
| 定义式长列举 | 指因…、…、…等原因 |
| 分层对称 | 对学校层面而言…对部门层面而言… |
| 四字对仗三连 | 识别粗放，干预就…，供给割裂，方案就… |
| 模板致谢 | 感谢…，感谢…，感谢… |

**改法 = 打散对称**：把并列项拆成有主次的叙述、长短句交错、模板句换成带具体情境的句子。**不是改词**。

**高风险段落**：综述 / 结论 / 研究对象 / 研究意义 / 致谢——"归纳出来的"天然整齐。
**低风险段落**：具体现象描述、有引用落点的问题—对策段——"看到的"天然有细节。

**预筛工具**：`tools/style_metrics.py` 自带结构对称扫描（11 条句式），实测命中数与 PaperPure 标红段落一一对应（旧稿 7 处 → 改后 0 处），可在**送检前**先自查。

## 七、第三层：具体信息密度（2026-09-18 新增 · 决定真假）

- **实测对照**：体医融合稿（PaperPure 20 多）锚点 0.82/千字、CV 0.54；人力资源稿初稿锚点仅 0.2/千字、CV 0.46，句法与结构全达标仍被判高风险——**通篇"正确的抽象话"本身就是最强的 AI 信号**。
- **硬线**：具体锚点（《规范/政策/标准》书名号 + 带单位的数字）**≥ 0.8/千字**；CV 保持在 **0.45-0.65**（<0.45 说明句长过于整齐）。
- **锚点来源四类**：教材/手册典型值、已发表文献的真实数据（样本量、框架维度、结论）、标准/规范规定值、常规工程取值区间。**凭空给精确数 = 编造。**
- **最省力的做法**：把已引文献里的真实信息写进正文——样本量（"887 份企业员工问卷"）、框架名（"技术嵌入、决策代理、组织适应、伦理治理"）、模型命名（"算法能力×心法能力"），既加密度又加可信度。
- **措辞**：仿真/推演写"仿真结果显示""数值计算表明"，禁用"实测""试验测得"；结论章写明"未经实物验证"。

**注意**：本基准适用于**本科毕业论文**；教师科研申报书、期刊论文另有更严谨的语体要求，不套用本文件。
