# 本科毕业论文（理工科方向）图纸与虚拟实验规范

> **适用**：机械、材料、电气、自动化、土木、化工、计算机等以图纸、数据表、实验表为主体的本科毕业论文。

## 一、两条红线（先记这两条，其余都是操作）

### 红线一：仿真 ≠ 编造，但**编造 ≠ 仿真**

- **虚拟实验是被允许的**——本科阶段用仿真或数值实验代替实物实验，是常见做法（有限元、运动学仿真、电路仿真、蒙特卡洛、数值积分）。
- **但"允许虚拟实验"不等于"可以随手写数"**。区别只在一件事：**数据是不是由模型算出来的**。
  - ✅ 走到位：选一个模型 → 设定参数（参数有来源）→ 跑出结果 → 结果满足该物理情境下的规律。
  - ❌ 不可以：先想好"结论应该是什么"，再倒着编一组好看的数字。
- **必须标注**：凡仿真产生的结果，表注与图注一律写明**"数据来源：本文虚拟实验（仿真）"**；正文首次出现时要说明所用模型与参数依据。**不得冒充实测**（"经实验测得"这类措辞不能用在仿真数据上）。
- **不能只给结论不给过程**：仿真脚本必须随论文交付（放附录或说明中），参数、假设、随机种子都要写清，别人要能复现。

### 红线二：AI 生图不能当工程图用

- **可以**用 AI 生图：原理示意图、结构概念图、应用场景图、装置外观示意——这类图**不含尺寸链**，只表达"长什么样、怎么连"。
- **不可以**用 AI 生图：三视图、装配图、零件图、公差与配合标注、机构运动简图、电路原理图、流程图、数据曲线——这些图上有**尺寸、编号、符号、坐标**，AI 生成的版本一定错，而且看上去像对的，答辩时一问就露。
- 判断标准一句话：**图里有没有"精确信息"（尺寸、编号、坐标、数值）**。有 → 用代码画；没有 → 可以用 AI 画，但画完要人工核对一遍有没有编造结构与标注。

## 二、图纸处理：按类型分流

| 图类型 | 生成方式 | 说明 |
|--------|---------|------|
| 机构运动简图、三视图、剖视示意 | **代码绘制**（matplotlib/numpy） | 尺寸取自参数表，标注与参数一致 |
| 装配/连接关系示意 | **代码绘制** | 用几何图元表达拓扑关系 |
| 流程图、技术路线图、系统框图 | **代码绘制** | 方框+箭头，字必须准 |
| 控制框图、信号流图 | **代码绘制** | 符号规范 |
| 数据曲线、散点、拟合线、柱状对比 | **代码绘制** | 由虚拟实验数据直接出图，坐标轴带单位 |
| 有限元云图/变形云图 | **代码绘制**（简化）或仿真软件截图 | 本科论文允许简化为分区着色示意 |
| 原理示意、结构概念图、应用场景 | **AI 生图** | 不含尺寸与编号；生成后人工核对 |
| 装置外观、产品形态 | **AI 生图** | 同上 |

**代码绘图统一要求**：300 dpi、白底、中文字体（SimHei 或宋体）、线宽 ≥1.0 pt、坐标轴标注物理量与单位、图题**在图的下面**（五号加粗居中）、图号按正文出现顺序编。

## 三、虚拟实验沙箱：怎么做才算规范

### 3.1 四步流程

```
① 选模型    → ② 定参数（每个参数写来源）→ ③ 跑仿真（固定随机种子）
                                          ↓
                        ④ 出结果：原始数据 CSV + 三线表 + 图 + 统计检验 + 仿真脚本
```

### 3.2 参数必须有来源

参数表里的每一行都要能回答"这个数从哪来"。可接受的来源：

1. **教材/手册**给定的典型值或取值范围（如钢的弹性模量 200-210 GPa、低碳钢屈服强度 235 MPa 级）；
2. **已发表文献**报告的取值（须真实可查，走文献实测流程）；
3. **标准/规范**规定值（如 GB 标准中的许用应力、公称尺寸系列）；
4. **常规工程取值区间**（无前三者时使用，须注明"按常规取值范围设定"）。

**不可接受**：凭空给一个精确到小数点后三位又无出处的数。

### 3.3 结果必须"像真的"：六项自洽检查

| 检查项 | 要求 |
|--------|------|
| **量纲与数量级** | 结果落在该物理量的合理区间（如钢的弹性模量不能算出 20 GPa） |
| **单调性与趋势** | 与理论规律一致（载荷↑则挠度↑、转速↑则扭矩↓等） |
| **边界与守恒** | 满足质量/能量/力平衡；端点条件成立 |
| **离散度合理** | 重复试验的波动在工程允许范围内（一般 ≤5%，视实验而调） |
| **组间差异与效应量匹配** | 有显著性就要给 p 值与效应量，且差异幅度与 p 值不矛盾（小样本出极小 p 值要警惕） |
| **与文献量级可比** | 与同题的公开研究结果处于同一量级，正文中给出对照 |

### 3.4 标注与措辞

- 表注/图注固定写法：`注：数据来源：本文虚拟实验（仿真），模型与参数见附录X。`
- 正文措辞用"仿真结果显示""数值计算结果为""模拟条件下"，**不用**"实测""试验测得"。
- 结论章要写一句局限：仿真数据未经实物验证，结论适用于设定参数范围。

## 四、实验表与数据表

- **一律三线表**（顶线 1.5 pt、表头下线 0.75 pt、底线 1.5 pt，无竖线）。
- 表头带**单位**；同一列有效数字位数一致；空值写"—"，不写 0。
- 统计类表至少给：n、均值±标准差、检验方法、p 值（精确值）、效应量。
- 正文先有"见表n"再出现表；表号按正文出现顺序。

## 五、工具用法

```bash
# 1) 跑虚拟实验：出原始数据 + 三线表 + 图 + 仿真脚本 + 参数来源说明
python tools/virtual_lab.py --model tensile --out outputs/实验_拉伸 --seed 20260918
python tools/virtual_lab.py --list                      # 看内置模型

# 2) 画图纸/曲线（代码绘制，含尺寸标注）
python tools/make_figures.py --list
python tools/make_figures.py --kind beam --out outputs/图_简支梁

# 3) 成稿与自查
python tools/build_thesis.py 源.md 出.docx
python tools/check_doc.py 出.docx
python tools/style_metrics.py 出.docx
```

**AI 生图**（仅限原理示意/概念图）：用图像生成工具出图后，**人工核对结构是否合理**，并在图注写"示意图，不含尺寸信息"。
