# 四平台语感规则速查

## 公众号
- 结构：标题党适度 + 开场钩子 + 小节标题 + 结尾引导关注
- 句式：中长句为主，允许书面；段落 3-5 行
- 禁忌：过度口语、无小标题的大段文字

## 小红书
- 结构：首句即结论/痛点 + emoji 分段 + 短句 + 结尾互动提问
- 句式：每句 ≤ 20 字，大量换行，emoji 每 2-3 段一个
- 禁忌：长段落、书面语、无 emoji

## 知乎
- 结构：结论前置 + 论证过程 + 数据/出处 + 补充边界
- 句式：允许长句，讲逻辑链，重证据
- 禁忌：情绪化断言、无依据的绝对表述

## 学术
- 结构：摘要 → 方法 → 结果 → 讨论，被动语态可接受
- 句式：精确、限定词充分（"在一定条件下""样本范围内"）
- 禁忌：口语、夸张形容、第一人称

## 通用
- 改写后必须回测：用 ai-flavor-rubric.md 复评，目标 ≥8 分
