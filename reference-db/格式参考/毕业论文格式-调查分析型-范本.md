# 毕业论文格式规范 — 调查分析型范本（来源：葛浩文毕业论文终稿 2026-09-09 实测提取）

> 提取来源：`C:\Users\hp\Desktop\毕业论文\葛浩文毕业论文终稿(1).docx`（池州学院体育学院 2026 届本科毕业论文，"芜湖市弋江区中年职场人群智慧体育信息服务现状调查与分析"）。
> 用途：调查分析型论文（现状调查类）的文字框架与格式母版规范。生成此类论文时按本规范执行。

## 一、整体框架（文字框架）

```
封面（本科毕业论文(设计) + 届别 + 题目 + 二级学院/专业/学生姓名/学号/指导教师/职称/完成时间）
学位论文原创性声明（+ 签名 + 日期）
摘要（中文）→ 关键词（3-5 个，分号隔开）
Abstract（英文）→ Keywords
1 绪论
  1.1 研究目的
  1.2 项目意义（实践价值 + 理论价值两段式）
  1.3 研究现状（宏观研究概括 → 精细研究不足 → 本研究对象/区域的研究空白 → 本文做什么）
2 研究对象与研究方法
  （章首总起段：调研目的→确定对象/方法/步骤/数据情况→为后文提供数据支持）
  2.1 研究对象（一句话：地域 + 年龄段 + 人群类型）
  2.2 研究方法
    2.2.1 文献资料法
    2.2.2 访谈法
    2.2.3 问卷调查法
3 调查结果与研究分析
  3.1 现状（分维度：认知程度 → 获取渠道 → 需求满意度；每小节=数据表+数据解读+访谈印证）
  3.2 存在的问题（小标题=四字概括+具体化，如"宣传覆盖不足，知晓率整体偏低"；每节内部"具体表现一/二/三"）
  3.3 优化对策（与 3.2 问题一一对应，每节"一是…二是…三是…"操作路径）
4 结论与建议
  4.1 研究结论（呼应研究方法+现状+问题，归纳式）
  4.2 建议（含研究局限说明 + 后续研究方向：扩样本/纵向跟踪/技术深化/多方联动）
参考文献（GB/T 7714）
致谢（母校→导师→老师同学→评委 四段式）
附录Ⅰ 调查问卷（逐题列出：题干+[单选题/多选题/问答题]+选项）
附录Ⅱ 访谈提纲（10 题左右，一问一行）
附录Ⅲ 查重报告
```

**框架要点**：
- 数字编号体系：章 `1`，节 `1.1`，目 `1.1.1`（无"第一章"式汉字编号）；
- 第 3 章是主体，**现状→问题→对策三段式**，问题与对策必须一一对应；
- 结果呈现 = 数据表 + 百分比解读 + 访谈质性材料印证，三角互证。

## 二、格式规范（实测值）

| 位置 | 字体 | 字号 | 其他 |
|------|------|------|------|
| 封面"本科毕业论文(设计)" | 楷体_GB2312 加粗 | 26pt(一号) | 居中 |
| 封面"(2026 届)" | 宋体 加粗 | 24pt | 居中 |
| 封面题目/各栏 | 宋体(栏目标签黑体) 加粗 | 15pt(小三) | 居中，下划线填空 |
| 原创性声明标题 | 方正小标宋_GBK 加粗 | 18pt(小二) | 居中 |
| 声明正文/签名 | 方正仿宋_GBK | 15pt(小三) | |
| 摘要/Abstract/章标题 | Heading 1（黑体系） | 默认 | 居中/左各按模板 |
| 摘要正文/全部正文 | 宋体 | 12pt(小四) | **行距固定 22 磅**，**首行缩进 2 字符(24pt)** |
| 节标题(1.1/2.2) | 宋体 加粗 | 12pt | 手动加粗，不缩进 |
| 目标题(2.2.1) | 宋体 加粗 | 12pt | 手动加粗，不缩进 |
| 表题（表 3-1 …） | Times New Roman | 11pt | 表上方居中，编号"表3-N"+表名+**(n=样本数)** |
| 英文/数字 | Times New Roman | 12pt | |
| 关键词行 | "关键词：" + 3-5 词分号隔开 | 12pt | |

**表格规范**：三列数据表（类别 / 人数 / 百分比），表题在上、编号连续（表3-1、表3-2…），标题注明 n 值；正文引用紧跟表后（"调查结果表明…仅38.89%的受访者…"）。

**参考文献规范（GB/T 7714）**：`[序号]作者.题名[文献类型].刊名,年,卷(期):页码.` 期刊[J]、会议论文集[C]//、学位论文[D]、专利[P]，中英文混排，英文作者姓前名缩写，DOI 可附。数量 15 条左右。

## 三、数据与方法表述句式（范本实测）

- 研究对象："本文把{地域}{年龄段}{人群类型}作为调研对象。"
- 问卷法："本次调研发放{N}份问卷，回收{M}份，有效问卷{K}份，有效回收率是{K/N}%，达到研究数据的要求。"
- 访谈法：对象构成（不同年龄/职业/学历以保证多样性）→ 访谈内容三方面 → 方式与时长（一对一面对面，15-20 分钟）→ 记录整理与用途（提取主要观点，为定性分析提供支持）。
- 文献法：数据库途径（知网/万方/图书馆）→ 检索主题 → 用途（概念/现状/特点整理作理论基础 + 政策文件作政策依据）→ 文献量（"查阅了40多篇相关文献"）。
- 结果解读："调查结果表明，…整体知晓率比较低…仅有38.89%的受访者选择…42.22%表示…18.89%表示不了解。"
- 访谈印证："访谈发现，多数调研对象把智慧体育看作…，甚至有部分调研对象表示从未听说…"
